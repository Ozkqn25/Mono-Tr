# 🏦 Monopoly Türkiye

Çok oyunculu online Monopoly — Türkiye özel baskı!

## 🚀 Railway'e Deploy (Ücretsiz, En Kolay)

1. **GitHub'a yükle:**
   ```
   git init
   git add .
   git commit -m "Monopoly Türkiye"
   git remote add origin https://github.com/SENIN_KULLANICI/monopoly-turkiye
   git push -u origin main
   ```

2. **Railway'de proje aç:**
   - railway.app'e git, GitHub ile giriş yap
   - "New Project" → "Deploy from GitHub Repo" → bu repoyu seç
   - Otomatik deploy olur, sana bir URL verir (örn: `https://monopoly-turkiye-xxx.railway.app`)

3. **Oyna!**
   - URL'yi arkadaşlarınla paylaş
   - Herkes aynı URL'ye girer
   - Biri oda oluşturur, diğerleri oda koduyla katılır

## 🎮 Nasıl Oynanır

- **Oda Oluştur:** Ad gir → "Yeni Oda Oluştur"
- **Katıl:** Oda kodunu gir → "Odaya Katıl"
- **Başlat:** Host (oda kurucu) "Oyunu Başlat" butonuna basar
- Telefon ekranından tam oynayabilirsiniz!
